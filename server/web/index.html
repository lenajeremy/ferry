      Safari only lets a page pass files to the share sheet over a secure connection. Trusting Ferry's certificate once gives it one, on your home network.

      1. Download Ferry's certificate

        Safari asks to download a configuration profile. Tap Allow, then Close.

        Download certificate
      2. Install it

        Open Settings, tap Profile Downloaded near the top, then Install.

      3. Trust it

        Settings › General › About › Certificate Trust Settings, then turn on Ferry.

      4. Open the secure page

        Use it from now on. To keep it a tap away, use Share › Add to Home Screen there.
